# Oiler — Умный автоматический смазчик мотоциклетной цепи (Firmware)

Добро пожаловать в репозиторий проекта **OILER**! Это любительская DIY-разработка автоматической системы смазки цепи для мотоциклов, созданная для того, чтобы навсегда забыть о баллонах со смазкой в дальних поездках и путешествиях.

В данном репозитории размещён открытый исходный код прошивки для микроконтроллера **ESP32**, который является «мозгом» системы.

## Как это работает?
Система работает в полностью автоматическом режиме и управляется со смартфона.
* **Связь:** Модуль ESP32 связывается со смартфоном по протоколу Bluetooth (BLE).
* **Автоматика:** Встроенный акселерометр смартфона понимает, когда мотоцикл начинает движение, и Oiler запускает точечную подачу масла на цепь через перистальтический насос согласно заданному интервалу.
* **Безопасность:** На светофорах, при прогреве или в пробках система молчит — масло не капает на асфальт и заднее колесо.

## Комплектация проекта (DIY варианты)
Проект разработан для мото-сообщества, поэтому доступен в трёх форматах:
1. **Готовый модуль под ключ:** Собранная плата в фабричном корпусе, залитая виброзащитным составом (поставил и поехал).
2. **KIT-набор:** Комплект фабричной печатной платы и радиокомпонентов для самостоятельной пайки.
3. **Голая прошитая ESP32:** Вариант для самостоятельной сборки и кастомного подбора комплектующих.
